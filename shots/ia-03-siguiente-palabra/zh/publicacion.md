标题: AI的回答其实是一场押注🎲

正文:
聊天机器人给你的回答不是一下子冒出来的：它是一场押注，一小块一小块地押。🎲🤖
首先，它把你的问题切成叫做 token 的小块：一个词或词的一部分。每个 token 变成一串数字，穿过一层又一层的计算。2020年，GPT-3 有1750亿个叫做“参数”的“旋钮”。
那另一头出来的是什么？只是一张清单：每个 token 成为下一个的可能性有多大。Llama 3（2024）要从12.8万个可能的 token 里选。如果你写“天空是”，“蓝色”的可能性很大；“绿色”很小。它选一个，接在末尾，然后把整个过程再来一遍，一个 token 接一个 token。
2020年，OpenAI 发现，把模型做得非常大以后，它只看几个例子就能学会新任务。但它选的是“可能的”，不是“真实的”：所以有时它会非常自信地答错。再加上一点随机性，同一个问题问两次，回答可能不一样。
注意：这不代表它完全不“思考”。2025年，Anthropic 的研究者从内部观察到，模型可以提前规划好几个词；即便如此，它还是一小块一小块地写出回答。
