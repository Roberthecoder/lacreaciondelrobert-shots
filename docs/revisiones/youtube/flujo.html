La Creación del Robert · Publishing tool · User flow

Only one user: the channel owner. No sign-up, no third-party accounts, no data from other users.

1
One-time authorizationThe owner signs in with Google and grants youtube.upload to the tool for his own channel. The refresh token is saved as an encrypted GitHub secret.
2
ReviewA new science short is produced, fact-checked and shown to the owner in the internal review page.
3
ApprovalThe owner clicks "Publish" and selects YouTube. Nothing is uploaded without this click.
4
UploadThe GitHub Actions workflow refreshes the access token and calls videos.insert with the owner's title and description (category Science & Technology, not made for kids, AI-voice disclosure on).
5
ResultThe Short appears on the owner's channel. The workflow logs only the video ID and URL. The owner can edit or delete it in YouTube Studio.
6
RevocationThe owner can revoke access any time at myaccount.google.com/permissions; the tool then stops working.
